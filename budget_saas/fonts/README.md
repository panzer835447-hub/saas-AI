# 字型

`NotoSansTC-Regular.ttf`、`NotoSansTC-Bold.ttf`：Noto Sans TC（思源黑體 繁中）一般與粗體，用於產生 PDF 報告。
由專案根目錄 `fonts/NotoSansTC-VF.ttf`（可變字型）以 fontTools 轉出 wght 400 / 700 兩個靜態檔，避免伺服器每次啟動都要重新轉換。
